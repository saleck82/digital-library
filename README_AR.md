# مكتبتك الرقمية — Starter MVP

## محتويات المشروع
- `index.html`: نموذج أولي يعمل في المتصفح، يدعم العربية والفرنسية والإنجليزية، البحث والتصنيف وبطاقات الكتب والصوتيات والفيديو والصور.
- `supabase_schema.sql`: مخطط اختياري لجدول بيانات المحتوى في Supabase.

## تشغيله من هاتف Android
1. نزّل محررًا مثل Acode من متجر Play.
2. أنشئ مجلدًا باسم `digital-library`.
3. أنشئ ملفًا باسم `index.html` والصق محتوى الملف المرفق.
4. افتح معاينة HTML في المحرر. إن لم تعمل المعاينة، افتح الملف باستخدام متصفح الهاتف.
5. جرّب البحث وتبديل اللغة والتصنيفات.

## إضافة المحتوى
في `index.html` ابحث عن `const items=[`.
لكل عنصر:
- `type`: أحد `book`, `audio`, `video`, `image`.
- `title`, `author`, `description`: قيم لكل لغة `ar`, `fr`, `en`.
- `url`: رابط مباشر مسموح لك باستخدامه. اتركه فارغًا أثناء التجربة.
- غيّر النصوص والصور والروابط بما يناسب المحتوى المرخص الذي تملكه.

روابط الملفات يجب أن تكون مباشرة ومتاحة عبر HTTPS إذا كان الموقع منشورًا. قد تمنع بعض مواقع الملفات التضمين داخل `iframe`. روابط الفيديو من منصات خارجية قد تحتاج إلى كود تضمين معتمد بدل رابط صفحة عادي.

## نشر نسخة ثابتة مجانًا
1. أنشئ حساب GitHub ومستودعًا عامًا للمشروع.
2. ارفع `index.html` إلى جذر المستودع.
3. افتح Cloudflare Pages واربط المستودع، واختر نشرًا ثابتًا دون أمر بناء؛ مجلد الإخراج `/`.
4. اختبر الموقع على الهاتف. تختلف الحدود المجانية وشروط الخدمة بمرور الوقت.

## ربط Supabase لاحقًا
1. أنشئ مشروعًا في Supabase.
2. افتح SQL Editor ونفّذ `supabase_schema.sql`.
3. لا تضع `service_role` key أو أي سرّ إداري في HTML أو JavaScript العام.
4. يمكن استخدام مفتاح `anon/publishable` في الواجهة فقط مع سياسات RLS صحيحة.
5. أنشئ لوحة إدارة محمية بتسجيل الدخول وصلاحيات تتحقق منها قاعدة البيانات.
6. لا تعتمد على `is_premium` في الواجهة وحدها لحماية محتوى مدفوع. يجب التحقق من الاشتراك على الخادم قبل إرجاع رابط الملف.

## العضويات الاختيارية
ابدأ بالمحتوى المجاني. لاحقًا أضف:
- حساب مستخدم وتفضيلات القراءة.
- اشتراكًا ودفعًا عبر مزود متاح قانونيًا في بلدك.
- تحققًا خادميًا من حالة الاشتراك.
- روابط تنزيل مؤقتة للملفات الخاصة، وسجلًا واضحًا للصلاحيات.

## حقوق النشر والأمان
لا ترفع كتبًا أو أفلامًا أو تسجيلات لا تملكها أو لا تملك إذنًا لاستخدامها. لا تضع مفاتيح سرية داخل ملفات الواجهة. اختبر الروابط والصلاحيات قبل إطلاق الموقع.
